# Telegram消息格式说明

## 消息格式

日报采用HTML格式推送，**文章标题是可点击的超链接**，保持阅读简洁。

### 格式示例

```
📰 今日资讯日报
📅 2024年03月19日 | 📊 共45篇资讯

────────────

📊 今日资讯概览
共收录 45 篇文章，来自多个优质信息源

🔥 热门推荐

1️⃣ 【推荐】美国财政部今日将执行历史最大规模回购
摘要：美国财政部预计今天将回购150亿美元本国国债...

2️⃣ 【推荐】阿里AI重组：集团CEO吴泳铭亲征
摘要：阿里成立全新AI事业群ATH...

📚 分类资讯

【BlockBeats】
• 花旗银行估算香港稳定币市场规模约1248亿港元
  摘要：花旗预计香港稳定币规模约1248亿港元...

【36氪】
• OpenAI发布GPT-5，性能提升300%
  摘要：新一代模型在多项基准测试中表现优异...

3. OpenAI发布新一代模型GPT-5

────────────
🤖 自动生成 | 由RSS日报机器人提供
```

### 超链接格式

**文章标题是可点击的超链接：**

在Telegram中显示为：
```
• 美国财政部今日将执行历史最大规模回购
```
（标题文字是蓝色的，点击即可跳转到原文）

**实际HTML代码：**
```html
• <a href="https://article-url.com">美国财政部今日将执行历史最大规模回购</a>
```

### 优势

✅ **简洁**：不显示冗长的URL链接  
✅ **美观**：标题本身就是链接，点击即可跳转  
✅ **稳定**：HTML格式Telegram解析更可靠  
✅ **清晰**：纯文本+emoji，层次分明  

## 格式规则

### 1. 标题格式

- 文章标题使用HTML超链接：`<a href="URL">标题</a>`
- 不单独显示链接URL
- 标题可点击跳转

### 2. 分组标识

- 📊 **概览**：今日统计信息
- 🔥 **热门推荐**：3-5篇重要文章
- 📚 **分类资讯**：按来源分组
- 💡 **今日亮点**：趋势总结

### 3. 文本格式

- 使用emoji增加可读性
- 摘要控制在80字以内
- 保持客观中立的立场
- 不使用Markdown符号

### 4. 标记说明

- 【推荐】：特别重要的文章
- 【来源名称】：文章来源分组

## 技术实现

### 模型提示词配置

文件：`config/generate_report_llm_cfg.json`

关键配置：
```json
{
  "sp": "...文章标题必须使用HTML超链接格式：<a href=\"链接URL\">文章标题</a>\n不要单独显示链接URL..."
}
```

### Telegram API参数

```python
payload = {
    "chat_id": chat_id,
    "text": message,
    "parse_mode": "HTML",  # 使用HTML解析
    "disable_web_page_preview": True  # 禁用链接预览
}
```

### 禁用链接预览

设置 `disable_web_page_preview: True` 可以：
- 避免消息中显示大量链接预览卡片
- 保持消息简洁
- 减少流量消耗

## 自定义配置

### 修改提示词

编辑 `config/generate_report_llm_cfg.json`：

```json
{
  "sp": "你的自定义提示词...",
  "config": {
    "model": "glm-4-flash",
    "temperature": 0.7
  }
}
```

### 调整摘要长度

在提示词中修改：
```
- 每篇文章摘要控制在80字以内  // 可改为50、100等
```

### 修改分组数量

```
- 对每个来源选择3-5篇重要文章  // 可改为2-3、5-8等
```

## 常见问题

### Q: 链接无法点击？

A: 检查：
1. 模型是否正确生成了HTML格式
2. Telegram是否正确解析HTML
3. 查看Actions日志中的日报内容

### Q: 标题格式错误？

A: 可能原因：
1. 提示词中链接URL包含特殊字符
2. 标题文字包含HTML特殊字符（<、>、&）

解决：模型会自动处理这些情况

### Q: 想显示完整链接？

A: 修改提示词，不使用超链接格式：
```
• 文章标题
  链接：URL
  摘要：...
```
